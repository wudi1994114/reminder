# Bead palette attribution

Color data: craft-color-codes by MakeBead (https://makebead.com)

Source: https://github.com/makebead/craft-color-codes (main, retrieved 2026-10-23).
The four JSON files are retained unmodified, including their embedded sources,
notes, status and licensing metadata. No third-party conversion code is included.

- `mard-221.json`: compilation and descriptive names by MakeBead, CC BY 4.0.
  See the preserved `LICENSE-DATA.md` and full `LICENSE-CC-BY-4.0.txt`.
- `perler-midi.json`, `artkal-s.json`, `hama-midi.json`: original color values
  from https://github.com/maxcleme/beadcolors under MIT. The full original MIT
  notice is in `LICENSE-BEADCOLORS-MIT.txt` and also in upstream `SOURCES.md`.
- `LICENSE-MAKEBEAD-MIT.txt` preserves upstream's code license for completeness;
  no upstream implementation is copied.
- `SOURCES.md` is the complete upstream provenance document, retained verbatim.

The application normalizes the imported color records to code/name/hex/rgb;
these derived records retain the same attribution and applicable licenses.
Display the `credit` exported by `palettes.mjs` with the selector and link
MakeBead to https://makebead.com where supported.

Color samples are community estimates: screen appearance is not a guarantee of
physical bead appearance. Buy beads by brand and code and check physical samples.

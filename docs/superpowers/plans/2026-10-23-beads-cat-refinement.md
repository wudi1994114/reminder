# 猫图拼豆精修方案与执行计划

用户要求：沿用提供的猫图解决暗部偏绿、毛发碎色和背景，持续查看实际输出，效果改善后再完成。所有转换仍在设备本地，原图不改写，不请求后端转换。

## 设计

- 感知配色：检查原图暖棕暗部与现有色板的匹配，修正全色板和限色色板共用的距离/色相约束；不能通过删除所有绿色修复，眼睛及其他图片真实绿色必须保留。
- 保边降噪：在颜色量化前平滑低对比纹理，结合现有小色岛清理；眼睛、瞳孔、鼻嘴、耳朵及透明轮廓属于强边缘，不做整图模糊。
- 本地背景：新增保留/去背景设置。对限幅图使用边界颜色模型与保边分割，保留中心主体并去除背景及与背景连接的地砖线，输出透明格；普通图默认保留，旧草稿继续保留。无法语义识别全部场景，设置可关闭，透明格可用已有画笔修补。
- 所有新选项进入设置变更提示及草稿；材料表从最终图纸计算。

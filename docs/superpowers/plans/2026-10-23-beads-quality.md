# 拼豆转换质量优化

> **For agentic workers:** Use executing-plans to implement this plan task-by-task.

**Goal:** 本地转换复杂插画和照片时，减少灰边、关键颜色丢失和低对比杂点，并用真实复杂图片验收。

**Architecture:** 保留图纸/编辑/材料表的数据结构。独立实现分模式取样、感知误差驱动的实际色板子集选择、保边杂点清理。已有草稿可读，缺少新设置按旧照片模式恢复。无需新增后端接口或依赖。

**Tech Stack:** 纯 JavaScript、uni-app Canvas、Node test、Playwright。

- [x] 先添加细线、黑白/点缀色保留、平坦区杂点、透明和禁用颜色的回归测试，验证旧实现失败。
- [x] 拆分颜色与取样/限色模块；照片使用线性光面积均值，插画使用颜色簇主导色并保护有足够覆盖的深色轮廓。限色以总误差降低量选色，迭代优化，并给源图实际存在的高对比细节加权。
- [x] 清理仅处理低对比的小孤岛，源边缘/高对比点不删除；允许关闭和轻度/标准设置。模式与清理强度纳入重新生成提示及草稿。
- [x] 使用公开复杂插画（神奈川冲浪里）及彩色照片，同图、同尺寸、同色板/色数比较；检查主体、边缘、杂点以及少色版本。保存原图来源、对比图、统计及本地耗时。
- [x] 检查真实 H5 页面选图、设置、编辑、草稿恢复、PNG导出，构建微信包。对比图不满意继续调整，不用测试通过代替图像验收。
- [x] 复核改动范围，提交并推送，记录源码/构建/微信上传各自状态。

## 验收标准

复杂图片在48/64/96格、8/16/24色下主体可辨；插画减少混色灰边，关键深色轮廓不过度膨胀；照片颜色过渡不被强行漫画化。禁用色不回流，透明边缘不产生隐藏RGB污染，材料统计与图纸一致。桌面性能与浏览器移动视口性能独立记录，不冒充手机真机耗时。

# 拼豆小工坊界面整理

用户选择更可爱活泼的方向。采用暖黄主操作、珊瑚色修图、拼豆圆孔标识与72格拼豆爱心空状态；收紧原图、品牌和去背景区域，将图纸预览提前。色号开关、缩放和全图复位集中在画布下方；编辑工具单独展开；导出方式与清晰度分组显示，材料及更多设置折叠。唯一主保存按钮固定在底部，显示当前导出方式和清晰度摘要。

画布按实际可用高度适配，给工具条、说明与保存栏预留空间，窗口调整后重新适配。微信原生Canvas在放大后会越过scroll-view盖住其他界面，已通过实际开发工具截图复现。现在离屏Canvas生成不超过2048像素的预览位图，由普通图片承载滚动和缩放；图纸、色号显示或文字可见性变化时刷新，双指缩放复用已有位图，放大结束更新文字。编辑坐标仍使用可见预览区域，高清导出仍从图纸独立绘制。

验证：

- Node 79项测试通过。新增实际可用高度与底部控件留空回归、原生预览位图复用和文字显示切换回归；均先验证旧行为失败。原生测试夹具补齐预览图片接口替身。
- HEAD归档的独立暂存工程只复制拼豆页面及Canvas文件，H5、微信小程序构建通过，未包含工作区其他页面、路由与依赖变动。
- H5 390×844：图纸顶部由约637像素提前至约308像素；完整画布、缩放工具条与常驻保存按钮均可见。选择图片生成5440颗/16色/64×85，缩放复位、擦除到5439并撤销、材料与更多设置展开、默认整张高清导出、刷新草稿恢复通过，没有页面异常。
- H5检查320、390、768像素宽度，无页面横向溢出，图纸适应预览框，底部保存按钮保持在窗口内。检查了空页面、生成、编辑、展开和图片预览状态。
- 微信开发工具：图纸预览约233.6×308，完整图、工具和保存栏可同时显示；2倍及8倍放大均限制在预览框内，文字可见性切换更新位图，固定保存栏不再被原生画布覆盖。编辑时双指不误涂，擦除/撤销恢复5440颗；高清临时PNG2868×4053，标准2164×3118；128×128图纸完整导出3700×3982。
- 相册API以成功替身验证保存控制流；真实手机相册写入与低端机性能仍需设备验收。开发预览码只表示开发预览可用。
- 检查主要文字颜色对比，正文约12.2:1、次级文字约5.1:1、色板署名约4.8:1；选项有可见选中态及aria-pressed，展开控件有aria-expanded，支持键盘焦点与减少动态效果。

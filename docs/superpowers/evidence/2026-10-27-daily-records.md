# 个人每日记录本地验收（2026-10-27）

## 实现范围

日历选中日期下方新增每日记录面板，支持个人体重、身高和纯文本日记；三项选填、历史日期补记、最近身高及原测量日期、摘要、就地编辑、草稿恢复、修改和确认删除。有记录日期显示短线标记。后端按认证账号隔离，记录 ID 加版本号防止更新、删除和删除再建时被旧请求覆盖。

草稿按账号和日期保存，保留原始记录身份、版本及编辑会话标识；迟到的保存/删除响应不会修改其他日期、账号或另一编辑会话的草稿。旧草稿不能借重建记录的新 ID 静默覆盖新记录。日记及测量值不进入通用请求日志，编码路径和 matrix 参数别名也经过回归验证。

# 拼豆色号与保存流程

按用户参考图增加每格品牌色号、黑白对比文字、四边行列编号、5格虚线与10格实线；导出保留完整材料表。色号预览可切换和缩放，关闭可看整体图案，坐标栏不参与修图点击。

用户真机反馈“已保存0张”。原版在微信开发工具、3倍像素密度下可生成1618×1836 PNG并收到相册保存成功回调；尚未取得用户手机的原始错误，不能据此认定根因是权限或图片尺寸。修改显式输出尺寸、等待绘制帧，并区分图片生成与相册写入失败。全部图片生成后再保存，失败保留预览，重试跳过已保存页，编辑后使旧图片失效。

验证：

- Node 69项测试通过。新增5项导出回归在修改前失败，修改后通过，覆盖尺寸、保存中断后的全部预览、续存、错误原因和编辑失效。
- HEAD归档的独立暂存工程只加入本次页面与Canvas文件，H5和微信小程序构建通过，没有混入其他页面、包配置的本地修改。
- H5 390×844：猫图生成64×85、5440颗、16色；色号切换保持cells，编号栏点击不修改，擦除第一格与撤销正确，刷新恢复，下载4张真实PNG，图片预览入口可用，没有页面异常。查看了页面、网格及导出文件。
- H5使用直接管理的DOM Canvas，防止uni-app尺寸监听覆盖手动设置的位图。验证显示尺寸1848×2436、位图1554×2048，点击范围与显示范围一致，位图仍保持上限。
- 微信开发工具：真实Canvas与canvasToTempFilePath生成4张PNG；相册API以成功和权限拒绝替身检查控制流，权限失败后保留全部预览且给出具体原因。该验证不代表真机相册写入已通过。

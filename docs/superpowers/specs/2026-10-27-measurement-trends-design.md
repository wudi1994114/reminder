# 体重与身高变化曲线

用户要求移除身高下的「10/1 测」等测量日期，未填写身高时沿用上次身高；点击体重或身高查看变化图表。保留现有紧凑布局及右侧编辑入口。

## 交互

- 常态只显示体重、身高及备注两行，不显示身高测量日期。编辑时用「未填写时沿用上次身高」提示，数值不自动重复写入当天。
- 点体重或身高，居中弹窗展示对应折线图，右上角「×」关闭；也支持点遮罩或Escape关闭。弹窗打开时不改变首页记录区高度，关闭后恢复到原指标入口。
- 默认近30天，可切换近90天、近一年，以日历当前选中日为截止日。日期、账号切换或离开页面时关闭弹窗，旧请求不得显示到新上下文。
- 图表仅使用实际存在的非空测量点，按日期比例定位，不填补缺测值。展示选中点日期和值，以及窗口内首末测量差；单点只画点，空数据给简短提示。失败可重试。
- 点击「编辑」继续编辑身高体重和备注；图表不替代原保存、草稿、冲突保护和删除流程。
- 用 uni-app canvas 渲染，兼容 H5/微信，弹窗按屏幕宽度自适应。H5隔离背景焦点、限制Tab焦点在弹窗中并锁定背景滚动，保持首页常态紧凑。

## 接口

新增 `GET /api/daily-records/trend?metric=weightKg&end=2026-10-27&days=30`。

- metric 只允许 weightKg / heightCm，days 只允许 30 / 90 / 365；end 为有效 YYYY-MM-DD。
- 身份仅来自 currentUser；时间范围含起止两日，start=end-(days-1)，最早为0001-01-01。
- 返回按日期升序排列的数组 `[{recordDate:"2026-10-01",value:62.5}]`，仅含当前账号、范围内、该指标非空的真实测量。
- 使用只读取日期和目标指标的查询，不返回备注、用户ID或完整记录。空结果为 []；未登录401；非法参数400并给中文错误。保持已有私密接口日志隐藏规则。
- 不改数据库结构，不回填沿用的身高测量。

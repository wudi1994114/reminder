# 拼豆页面设计约定

## Visual direction

暖黄手作小工坊。页面为浅黄色，操作区域为白色，珊瑚色用于修图。空页面展示由规则拼豆格子组成的爱心，生成后使用紧凑标题与原图栏。

## Tokens

- 页面 `#fff9ec`，面板 `#ffffff`，文字 `#3b3028`，次级文字 `#776858`，分隔 `#eddfca`。
- 主操作 `#ffca55`，选中背景 `#fff1c5`，修图文字 `#a94f3d` / 背景 `#fff0e8`。
- 系统无衬线字体。页面标题22px，生成后18px，区块标题15–16px，正文12–14px。
- 圆角约8–15px，实体边框，无装饰性模糊阴影。

## Layout

空状态：标题、拼豆爱心与选图按钮、品牌、草稿恢复、更多设置。

生成状态：紧凑原图与品牌/去背景、预览标题与修图、按实际可用高度显示的完整画布、色号/缩放工具、细节调整、导出选项、材料与更多设置。底部固定显示当前导出摘要和唯一主保存按钮，并预留安全区及正文底部间距。

## Components and states

主保存用暖黄色，修图用珊瑚色，普通选项用低对比填色及选中边框。工具和材料色块使用小圆孔呼应拼豆。按钮有禁用、按下和焦点状态；保留真实加载、失败原因及重试。导出成功仅短暂弹出“导出成功”，不新增预览区、自动保存说明或成功长文；操作说明和色卡参考提示不常驻主界面，色板署名收在更多设置中。动效只用于按下反馈，遵循减少动态效果设置。
